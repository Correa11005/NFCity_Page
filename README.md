# NFCity

Página web estática de NFCity.

## Cómo verla
Abre la carpeta en VS Code, instala la extensión Live Server y haz clic derecho en index.html > Open with Live Server.

## Cómo editar
- Número de WhatsApp: js/config.js (código de país + número, sin + ni espacios)
- Colores y tipografías: variables al inicio de css/styles.css
- Imágenes: las imágenes están en assets/ con sus nombres originales
- Textos: index.html
